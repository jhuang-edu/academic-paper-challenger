# 数据统计挑战指标数学口径与判读指南（Statistical Forensics Guide）

本文档阐述 `scripts/data_forensics.py` 所实现的全部统计复算与数据真实性检验数学原理、判定阈值及边界保护机制，用于 Stage 2 审计判读与方法论抗辩。

---

## 1. 双口径四分位数（`PERCENTILE.INC` vs `PERCENTILE.EXC`）

设升序排列样本为 $x_0 \le x_1 \le \dots \le x_{n-1}$，分位点 $p \in (0, 1)$：
- **包容插值口径（`PERCENTILE.INC`，对应 Excel `PERCENTILE.INC` / NumPy `linear`**）：
  $$k = p(n - 1), \quad lo = \lfloor k \rfloor, \quad hi = \lceil k \rceil, \quad Q_{\text{inc}}(p) = x_{lo} + (k - lo)(x_{hi} - x_{lo})$$
- **互斥插值口径（`PERCENTILE.EXC`，对应 SPSS / R type 6**）：
  当 $\frac{1}{n+1} < p < \frac{n}{n+1}$ 时，
  $$pos = p(n + 1) - 1, \quad lo = \lfloor pos \rfloor, \quad hi = \lceil pos \rceil, \quad Q_{\text{exc}}(p) = x_{lo} + (pos - lo)(x_{hi} - x_{lo})$$

**审计意义**：当样本量 $N \le 40$ 时，`INC` 与 `EXC` 算出的 $Q_1$、$Q_3$ 与 $IQR$ 往往存在明显尾差。论文必须在统计方法节或表注显式声明所采用的插值口径，避免审稿人使用不同统计软件复算时误以为数值造假。

## 2. 列间强共线性检验（Pearson $r$ & Spearman $\rho$）

- **Pearson $r$**：度量线性共变强度；
- **Spearman $\rho$**：严格对双变量计算**带并列平均秩次修正（average tie ranks**）后的秩次向量，再计算 Pearson $r$（不使用在存在大量并列值时会失真的简化公式 $1 - \frac{6\sum d^2}{n(n^2-1)}$）。
- **警戒阈值**：$|r| \ge 0.90$ 或 $|\rho| \ge 0.90$ 触发 `HIGH_COLLINEARITY` 警告。
- **鉴别原则**：
  - *人为合成特征*：两列满足精确线性关系（如 $y = a x + b + \epsilon$ 且残差极小，$r > 0.99$），往往无合理物理/行为机制解释；
  - *真实同源特征*：例如“同一评审员对同一份复杂材料的人工耗时 vs 辅助审阅耗时”天然共享材料长度与信息密度基线，此时应在文中补充测量学解释，并同步报告配对差值、分亚组独立均值及中位数/IQR 等稳健指标。

## 3. Wald-Wolfowitz 游程检验（Runs Test）

给定保持原始记录顺序的数值序列，以全局中位数 $M$ 为界剔除等于 $M$ 的点，映射为二值符号序列（`+` 与 `-`），记数量分别为 $n_1, n_2$（$n = n_1 + n_2 \ge 10$ 且 $n_1, n_2 > 0$），连续同号段数记为游程数 $R$：
$$\mu_R = \frac{2 n_1 n_2}{n} + 1, \quad \sigma_R = \sqrt{\frac{2 n_1 n_2 (2 n_1 n_2 - n)}{n^2 (n - 1)}}, \quad Z = \frac{R - \mu_R}{\sigma_R}, \quad p = \operatorname{erfc}\!\left(\frac{|Z|}{\sqrt{2}}\right)$$

- **$Z < 0$ 且 $p < 0.05$**：显著**聚簇**（例如数据按单调排序或先全批正例后全批负例分段拼接）；
- **$Z > 0$ 且 $p < 0.05$**：显著**过度交替**（例如人为按组别一对一交替构造或按类别轮流归档）。
- **合规处置**：若原始实验确实采用“随机打乱顺序施测、但事后按分组编号归档整理台账”，须在方法章节显式区分**施测呈现序（随机**）与**台账归档序（按组排列**）。

## 4. 末位数字均匀性与 Benford 首位数定律边界

1. **末位数字 0–9 均匀性卡方检验（$df = 9$**）：
   - **关键细节**：必须从**原始字符串**直接抽取数字主体最末一位数字字符（如 `"3.20"` 提取 `'0'` 而非转浮点丢失尾零）。
   - 当有效样本数 $n \ge 20$ 且 $\chi^2$ 上尾概率 $p < 0.05$ 时，提示末位分布非均匀（如过度集中于 `0`/`5`）。需区分“人为拍脑袋取整”与“测量界面最小刻度步长（如 `0.1` 或 `0.5` 档位）”。
2. **Benford 首位数 1–9 检验（$df = 8$**）：
   - 理论比例 $P(d) = \log_{10}(1 + 1/d)$。
   - **严格适用边界（防滥用红线**）：只有当正值样本数 $n_{\text{pos}} \ge 30$ **且**数值跨越至少 1 个数量级（$\max / \min \ge 10.0$）时，偏离才具数据核查意义。对 1–5 分制李克特量表、百分比得分或窄区间操作耗时（如 1–8 分钟），Benford 定律天然不成立，不得作为造假依据。

## 5. 离群值、重复行与对照评估指标

- **3-IQR 极端离群值**：超出 $[Q_1 - 3\cdot IQR,\, Q_3 + 3\cdot IQR]$ 的样本需核实原始记录，并在正文提供“剔除极值前后”的稳健性对比。
- **重复行与同特征行**：识别完全重复记录及“除样本 ID 外全部特征列相同”的记录，防范复制粘贴错录。
- **混淆矩阵与 McNemar 配对检验**：
  - 精确计算一致率 $p_o$、Cohen's $\kappa = \frac{p_o - p_e}{1 - p_e}$、Precision/Recall/Specificity/F1；
  - 对非对角分歧格 $(b, c)$ 同时输出 Edwards 连续性修正卡方 $p_{\text{chi2}}$ 与精确双侧二项检验 $p_{\text{exact}} = \min\!\left(1, 2\sum_{k=0}^{\min(b,c)} \binom{b+c}{k} 0.5^{b+c}\right)$；当 $b + c < 25$ 时优先以精确二项 $p_{\text{exact}}$ 为准。
