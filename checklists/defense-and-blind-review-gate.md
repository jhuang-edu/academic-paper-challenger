# 终稿交付与盲审放行刚性闸门（Gates G1–G8）

本闸门清单用于 Stage 3 收尾阶段。遵循**刚性一票否决原则**：只要 G1–G8 中**任意一项为 `FAIL`**，严禁签发论文终稿放行，必须回退修正对应源码并重新执行自动化复核。

---

## 闸门总表（G1–G8）

| 闸门 | 闸门名称 | 核心检验内容 | PASS 判定条件 | 一票否决触发条件（FAIL） |
|---|---|---|---|---|
| **G1** | **零指令与零符号泄漏闸门** | 内部 Prompt 指令、脚本代号、旧草稿行号、调试种子、裸变量名及未渲染 Markdown/HTML 符号（`**`, `` ` ``, `>`, `<br>`, 围栏、注释、批注/修订） | `doc_leak_scanner.py` 对源码与最终交付件（含 `.docx`）扫描 **0 处未豁免 FAIL 告警** | 终稿存在任意内部代号、占位符、批注/修订或未渲染 Markdown 符号 |
| **G2** | **多载体单一事实源一致闸门** | 合稿、分章、附录与最终渲染 Word/PDF 在段落、样本属性、流程及结论上的一致性 | `doc_leak_scanner.py --compare` 覆盖率 100%，且正附录人工对照 **0 处矛盾** | 分章与合稿不同步，或正文与附录对同一样本/设计结论互相冲突 |
| **G3** | **图表编号与目录索引同步闸门** | 图表编号连续性、正文引用可达性、图清单/表清单标题与页码同步 | `cross_table_reconciler.py` 0 处断号/孤儿引用/清单不一致，且成品页码真实准确 | 存在断号、孤儿引用、硬编码错误页码、缺失页码或漏列附录表 |
| **G4** | **时序与规则状态机自洽闸门** | 研究时间轴、版本演进（初版 `v1.0` vs 复盘 `v1.2`）、软/硬拦截机制与状态枚举统一 | 时间线无倒挂，试运行前后版本界定清晰，全稿状态标签集合完全统一 | 出现“用事后复盘规则倒填事前实验”的时空穿越悖论或枚举混乱 |
| **G5** | **全量算术与量纲守恒闸门** | 跨表加总、分项与合计平账、跨期/年化量纲明确、样本量分母守恒与分位数口径声明 | `cross_table_reconciler.py` 与 `data_forensics.py` 复算误差 $\le \text{tol}$ | 存在表格算术不平、跨时间量纲混用或样本总数前后不守恒 |
| **G6** | **数据异常信号处置闭环闸门** | 列间共线性（$|r| \ge 0.90$）、游程检验、末位数字/Benford 偏离、重复行与 3-IQR 极值核查 | 每项红旗均已修正计算错误或补充真实测量学解释+稳健性指标（理论类标记 `N/A`） | 存在未解释的高危合成红旗，或发现为迎合检验擅自篡改实测值 |
| **G7** | **断句流畅度与去 AI 腔闸门** | 句长变异系数 CV、长难句上限、机械断句残句、AI 连接词密度/三连排比及真实组织摩擦感 | `prose_rhythm_audit.py` 达标（无残句 `FAIL` 且 `CV >= 0.35`），中英文摘要细节对齐 | 存在断句病句、严重公文套话排比或缺乏真实摩擦与失误的真空叙事 |
| **G8** | **法规、文献与脱敏伦理闸门** | 法规/标准条款号与生效时态核验、文献迁移逻辑成立、研究主体全稿规范脱敏 | 全部法条文号经原文核实无误，化名标注统一且无实名隐私残留 | 法条条款张冠李戴、引文观点强行嫁接，或正文/致谢泄露应脱敏主体 |
