# 五大通用维度 50 点找茬清单模板（Rapid Audit 50-Point Checklist）

本清单用于 Stage 1（30 分钟地毯式找茬），覆盖任意学科论文中最高发的 **50 个典型缺陷点（D1-01 至 D5-10**）。不适用项可填 `N/A` 并注明原因，其余项须附上精确锚点。

---

| D1-02 | 核查文稿顶部与页眉页脚是否残留未删替换批注 | 顶部出现“正式提交前按指南替换真实数据” | `doc_leak_scanner.py` + 人工 | | [ ] |

## D3：时序穿越、实验设计与规则—数据自相矛盾（10 点）

| 编号 | 检查动作 | 跨学科高危信号示例 | 对应工具 / 核查方式 | 锚点记录 | 状态 |
|---|---|---|---|---|---|
| D3-01 | 排查是否把事后复盘才补充的规则倒填进事前基线设计 | 方案字典写着“全量拦截”，但该条规则是试运行复盘才新增 | 核对版本标记（`v1.0` vs `v1.2`） | | [ ] |
| D3-02 | 排查试运行“软性提示”与定稿“硬性阻断”的机制混淆 | 设计称软提示，后文又解释因系统未锁死导致人工误操作 | 对照系统设计节与试运行异常复盘 | | [ ] |
| D3-03 | 核查边界样本分类口径在规则表与结果表之间是否一致 | 同类边界资历样本，A 样本直接通过而 B 样本触发升级却未说明差异 | 逐一复核边界样本判定依据 | | [ ] |
| D3-04 | 核查核心指标（如遗漏率、召回率）的操作定义是否明确且一致 | 分母未写明是否包含边界保守淘汰样本或无效样本 | 核查指标公式节与误差分析表 | | [ ] |
| D3-05 | 核查协同复核/升级样本的流转路径与累计耗时是否自洽 | 总升级计 5 例耗时 26 分钟，但其中 2 例流程描述成未进入协同 | 复核流程分支与总耗时加总表 | | [ ] |
| D3-06 | 核查基准真值封存时点与实验轮之间是否存在“事后反改基准” | 试运行复核结果是否反向改写了双盲前封存的专家基准 | 核查盲审方案与基准封存声明 | | [ ] |
| D3-07 | 核查多人/多轮盲评施测者编制与洗脱期设计是否一致 | 一处写“单人洗脱四周重评”，另一处写“双人平行盲评” | 对照研究设计、伦理/流程附录 | | [ ] |
| D3-08 | 检查计时方式、呈现顺序随机化与疲劳效应控制说明是否完备 | 只报平均耗时却未交代日志计时粒度及序列打乱设计 | 核查实验施测规程段落 | | [ ] |
| D3-09 | 核查提示词/判定状态机的枚举值在正文、代码、表格中是否统一 | 设计规定三态枚举，结果表却冒出第四种自定义标签 | 核对全稿状态标签枚举集合 | | [ ] |
| D3-10 | 检查法规知识库列表或基准回归测试样本集编号是否完整无残缺 | 声称“12 份清单/10 份测试集”，实际只列了 6 份或部分编号 | 清点正文与附录完整清单条目数 | | [ ] |

## D4：跨表算术、量纲错位与商业/资源逻辑悖论（10 点）

| 编号 | 检查动作 | 跨学科高危信号示例 | 对应工具 / 核查方式 | 锚点记录 | 状态 |
|---|---|---|---|---|---|
| D4-01 | 核查投入产出/消融账本左右分项与右侧总计是否平账 | 左侧分项之和为 44，右侧各角色工时汇总却写 42 | `cross_table_reconciler.py` + 手算核对 | | [ ] |
| D4-02 | 核查表格纵向明细累加、小计行与总计行是否精确相等 | 明细直接加总与含小计行的表容易算重或漏加 | `cross_table_reconciler.py` (`TABLE_COL_SUM_MISMATCH`) | | [ ] |
| D4-03 | 排查同一张表中跨时间量纲的直接混用 | 把“18 个月累计 74 份”与“年均运营工时”直接并列对比 | 检查各表表头与正文周期修饰词 | | [ ] |
| D4-04 | 核查跨期折算（如除以 1.5 转年化）的取整尾差说明 | 分岗位四舍五入后相加比总计少 1 或多 1 却未加注文 | 复算折算比率并检查表注 | | [ ] |
| D4-05 | 审查全局业务规模与聚焦研究子集的负荷叙事张力 | 前文称“全年仅 500 份工作量”，访谈却抱怨“人手严重过载” | 核对组织全口径负荷与子集占比 | | [ ] |
| D4-06 | 检查执行角色名称（RACI 矩阵与成本表）是否前后一致 | 预算表出现“外聘独立审计员”，RACI 表却只有内部人员 | 跨章节提取全部角色编码逐一比对 | | [ ] |
| D4-07 | 核查四分位数（IQR）与置信区间算法口径声明 | 未注明 `PERCENTILE.INC`（线性插值）或 `EXC` 导致复算偏离 | `data_forensics.py` 双口径比对 | | [ ] |
| D4-08 | 核查混淆矩阵单元格 `TP+FP+FN+TN` 与组内样本总量是否守恒 | 阳性/阴性基数跨表飘移或错判样本数之和不等于误判总数 | `data_forensics.py` (`--ref-col` `--pred-col`) | | [ ] |
| D4-09 | 审查商业 ROI 或收益归因是否漏算隐性返工与空缺成本 | 只算主流程分钟数节省却发现不够覆盖维护工时，导致 ROI 为负 | 重算全链路直接+间接管理收益 | | [ ] |
| D4-10 | 核查比例列与百分比基数（分母）跨表是否漂移 | 前表以“总入组数”为分母，后表以“有效完成数”为分母未标注 | 逐表复算分子/分母定义 | | [ ] |
