# 五大类缺陷分类学与检测信号图谱（Five-Dimension Taxonomy）

本文档为 Stage 1（D1–D5）提供跨学科的学理定义、高危正则表达式信号库、三阶否定语境豁免规则及五大学科集群典型映射。

## 1. D1–D5 缺陷分类学定义

| 维度代码 | 维度名称 | 核心病灶本质 | 常见生成路径 |
|---|---|---|---|
| **D1** | **内部产物与指令穿帮** | 写作辅助过程元数据泄漏进学术正文本体 | 从 Prompt 模板、代码脚本、草稿笔记拷贝文本时未剥离行号、种子与防越界约束 |

## 2. 通用自动检测信号与三阶否定豁免机制

`scripts/doc_leak_scanner.py` 内置以下通用检测线索（所有线索均**不绑定特定学科或特定论文**）：

| 信号规则 ID | 适用载体 | 典型捕获模式 | 是否支持否定豁免 |
|---|---|---|---|
| `DOCX_UNRENDERED_BOLD` / `BACKTICK` / `QUOTE` / `RAW_FENCE` | 仅 `.docx` | Word 文本流中残留 `**文字**`、`` ` ``、行首 `>` 或 ` ``` ` 围栏（自动跳过等宽代码样式段落） | 否（成品绝不允许） |
| `RAW_HTML_BR` / `HTML_COMMENT_LEAK` | `.docx` / 全载体 | `<br>`、`<!-- ... -->` | 否 |
| `PLACEHOLDER_LEAK` | 全载体 | `TODO`, `TBD`, `FIXME`, `XXX`, `待补充`, `正式提交前` | 是 |
| `DRAFT_LINE_REF` | 全载体 | 孤立草稿行号 `L204`、`L197–L219`（自动避开 `L1/L2` 正则化单数字术语） | 是 |
| `RANDOM_SEED_LEAK` | 全载体 | `seed=42`, `random_state=0`, `torch.manual_seed=...` | 是 |
| `BARE_SNAKE_CASE` | 全载体（中文语境） | 在中文散文或表格中裸露的 `snake_case` 变量名（`--mode cs` 时放宽反引号内术语） | 是 |
| `AI_SURGERY_THREAD` | 全载体 | “与原有表述相比”“保留原研究”“按……指南替换”“仅锁定……”等改写拼贴痕迹 | 是 |

### 三阶否定语境豁免窗口（防止误杀研究边界声明）
对允许豁免的规则，扫描器自动执行三阶上下文判定：
1. **第一阶（前置局部否定窗口**）：检查命中词前 `18` 字符内（不越过上一句号/分号/换行）是否出现“不涉及 / 排除 / 未采用 / 禁止 / avoid / without”等否定词；
2. **第二阶（转折阻断与右侧补强**）：若否定词后又出现“但 / 然而 / 不过 / however / yet”，则判定为**转折阻断**，不予豁免（例如“虽不涉及 A，但实测使用了 seed=17”仍报 `FAIL`）；若命中词右侧 `10` 字符内有“已清除 / 已脱敏 / excluded”，则补强豁免；
3. **第三阶（分级落盘**）：豁免成立时降级为 `INFO` 并标记 `exempted=true`，保留完整审计踪迹而不阻断构建。

## 3. 五大学科集群高发缺陷映射表

| 学科集群 | D1/D2 典型翻车点 | D3/D4 典型翻车点 | D5 典型翻车点 |
|---|---|---|---|
| **工科** | 消融实验表印出 `seed=42`；代码块渲染为灰色表格后仍混有 `**` | 消融表分项准确率与总表不一致；用测试集误差调参后回写进基线设定 | 把未正式颁布的行业团体标准写为“现行强制国标”；强行拆句导致“实验结果表明。” |
| **理科** | 仪器参数表裸露脚本变量 `baseline_offset`；正附录样本编号错位 | 跨批次实验观察期不同步（30 天 vs 90 天）直接横向比绝对累积量 | 物理量纲缩写（如 `Fig. 1`、`et al.`）被不当分句工具截成碎句 |
| **社科** | 访谈编码表直接印出草稿文档行号 `L180`；附录留有 `TBD` | 问卷回收总量与分群体加和相差 2 份；洗脱期与盲评人数前后冲突 | 法律法规条款号张冠李戴（将处罚条款引为隐私保护原则条款） |
| **经管** | 标题带有防越界提示词；Word 商业测算表满是 `<br>` 与星号 | 投入产出账本左右工时不平；忽略隐性返工与空缺成本导致 ROI 倒挂 | 英文摘要遗漏中文摘要的核心时限约束；套用泛化管理文献未交代行业迁移条件 |
| **医学** | 伦理批件占位符未替换；Word 保留审阅批注或未接受修订痕迹 | 纳入排除标准中途修订却未分版本标注；双盲真值被事后复核反向修改 | 临床指南发布与施行日期错位；把动物实验结论直接混述为临床队列结论 |
