# 全链路数据对账与数据核查核查清单（24 项）

本清单用于 Stage 2（全链路数据校验与统计挑战），共分 **4 个模块 24 项**。纯理论/纯定性无台账论文可整体标为 `N/A` 并记录豁免理由；实证类论文须逐项核查留痕。

---

## 模块一：样本量与抽样框守恒（6 项）

| 编号 | 检查项 | 核查标准与通过条件 | 对应工具 / 方法 | 状态 |
|---|---|---|---|---|
| S2-01 | 总体样本量 $N$ 跨表一致 | 正文文本、数据台账行数、结果汇总表及附录的样本总量完全一致 | `data_forensics.py` (`row_count`) | [ ] |
| S2-02 | 分层/亚组样本加总守恒 | 各分层或试验组样本数之和严格等于总体 $N$（零漏计、零重计） | `cross_table_reconciler.py` | [ ] |
| S2-03 | 剔除/失访/异常样本闭环 | 所有从原始台账剔除或判定无效的样本均交代去向与数量 | 原始日志 vs 纳入分析集对照 | [ ] |
| S2-04 | 数据采集时间窗口一致 | 正文声称的统计起止年月与台账记录覆盖时间完全吻合 | 核查台账时间戳边界 | [ ] |
| S2-05 | 盲评/分组施测均衡性交代 | 多施测者或平行分组时，明确交代随机打乱顺序或交叉平衡设计 | 方法章节人工审读 | [ ] |
| S2-06 | 非概率/配额抽样外推边界 | 若采用分层配额抽样，明确声明样本阳性率不等同于自然总体基准 | 局限性节核查 | [ ] |

## 模块四：数据异常信号响应决策树（8 项）

| 编号 | 检查项 | 响应分支与合规处理要求 | 对应工具 / 判定规则 | 状态 |
|---|---|---|---|---|
| S2-17 | 共线性检查（Pearson $r$ / Spearman $\rho$） | 若 $|r| \ge 0.90$：先排查是否人为线性生成；若属真实同源基线所致，须补充测量学解释及去相关性稳健指标 | `data_forensics.py` (`HIGH_COLLINEARITY`) | [ ] |
| S2-18 | Wald-Wolfowitz 游程检验 | 若 $p < 0.05$：区分“按对象类别交替归档序 vs 随机测试呈现序”与“分段凑数”，归档序问题须明确记录呈现机制 | `data_forensics.py` (`RUNS_NON_RANDOM`) | [ ] |
| S2-19 | 末位数字 0–9 均匀性检验 | 当 $n \ge 20$ 且 $p < 0.05$：核查界面/仪器固定记录粒度（如 0.1 或 0.5 档），区分人为凑整与量具分辨率 | `data_forensics.py` (`LAST_DIGIT_BIAS`) | [ ] |
| S2-20 | Benford 首位数定律边界核验 | 仅当正值 $n \ge 30$ 且跨越数量级 $\ge 10$ 倍时启用；窄区间评分或限定耗时不得误判为 Benford 异常 | `data_forensics.py` (`benford_test`) | [ ] |
| S2-21 | 完全重复行与同特征行排查 | 检出重复行或除 ID 外全同特征行时，须核实是否真实多样本同分值，抑或复制粘贴误录 | `data_forensics.py` (`DUPLICATE_*`) | [ ] |
| S2-22 | 3-IQR 极端离群值核查 | 对超出 $[Q_1 - 3\text{IQR}, Q_3 + 3\text{IQR}]$ 的样本，须逐个核实原始记录并同时报告含/不含极值的稳健结果 | `data_forensics.py` (`EXTREME_3IQR_OUTLIER`) | [ ] |
| S2-23 | 固定小数步长网格探测 | 对呈现高比例离散步长对齐的列，确认并在正文写明原始计时或测量仪器的最小精度单位 | `data_forensics.py` (`DISCRETE_STEP_GRID`) | [ ] |
| S2-24 | 真值不可篡改红线签核 | 确认全部处置未对任何锚点数据或实验结局做人为涂改，所有调整均符合学术伦理与可复现原则 | 审计人复核原始版本对比 | [ ] |
